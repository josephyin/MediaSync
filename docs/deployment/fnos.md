# 飞牛 fnOS 图形化安装

本文说明如何在飞牛 fnOS 的 Docker 图形界面直接安装 MediaSync。界面文字可能
随 fnOS 版本略有变化，核心配置包括镜像、端口、持久化目录和用于一键更新的
Docker Socket。

## 1. 准备目录

在飞牛文件管理器中创建一个专用目录，例如：

```text
/vol1/1000/docker/mediasync
```

该目录会同时保存数据库和运行时密钥。确认 Docker 容器对目录有读写权限，不要
把它设为只读。

## 2. 拉取镜像

1. 打开飞牛的“Docker”应用；
2. 进入“镜像仓库”或“镜像”；
3. 搜索 `josephyjq/mediasync`；
4. 选择精确标签 `v0.2.0-rc.28`；
5. 下载镜像。

候选版本建议使用精确标签，便于升级和回滚。

## 3. 创建容器

选择已下载的镜像并创建容器：

| 设置项 | 建议值 |
|---|---|
| 容器名称 | `mediasync` |
| 自动重启/开机自启 | 开启 |
| 网络模式 | 默认 Bridge |
| 特权模式 | 关闭 |
| 容器命令 | 留空，使用镜像默认入口 |

不要覆盖镜像命令。官方新安装默认配置 Docker Socket，以便在后台直接更新；
飞牛无法仅根据镜像自动带出宿主机绑定，因此必须按第 5 节手工确认映射。

## 4. 端口映射

添加一条 TCP 端口映射：

| 本地端口 | 容器端口 |
|---:|---:|
| `9090` | `9090` |

镜像只声明一个 `9090` 端口，飞牛应自动生成这一条映射。本地端口可以改为其他
未占用端口，容器端口必须是 `9090`。不需要映射内部 API
端口 `8000`。

## 5. 存储映射

添加一条文件夹映射：

| 飞牛本地路径 | 容器路径 | 权限 |
|---|---|---|
| `/vol1/1000/docker/mediasync` | `/data` | 读写 |
| `/var/run/docker.sock` | `/var/run/docker.sock` | 读写 |

本地路径按你的存储池和用户目录实际情况修改，容器路径必须是 `/data`。

Docker Socket 映射等同于授予 MediaSync 宿主机 Docker 管理员权限。它是官方
单容器新安装的推荐默认值，但飞牛会要求用户手工添加并确认。只使用可信官方镜像，
不要把管理端口暴露到公网。不需要一键更新时可以省略第二行，其他功能不受影响。

## 6. 环境变量

镜像默认提供：

| 变量 | 默认值 |
|---|---|
| `ADMIN_PASSWORD` | `admin` |
| `IMAGE_DEFAULT_ADMIN_ONLY` | `true` |
| `SESSION_COOKIE_SECURE` | `false` |

建议在创建容器时把管理员密码改为自己的强密码：

| 变量 | 值 |
|---|---|
| `ADMIN_PASSWORD` | 你自己的强密码 |
| `SESSION_COOKIE_SECURE` | `false` |

如果通过 HTTPS 反向代理访问，把 `SESSION_COOKIE_SECURE` 改为 `true`。

普通首次安装不要自行填写 `SECRET_KEY` 和
`CREDENTIAL_ENCRYPTION_KEY`。从 rc.2 迁移已有数据库时除外。

## 7. 启动和登录

保存配置并启动容器。等待容器状态变为“健康”后访问：

```text
http://飞牛_IP:9090
```

用户名默认为：

```text
admin
```

默认登录信息：

```text
用户名：admin
密码：admin
```

首次登录后必须点击管理后台左下角管理员区域的锁形按钮修改为强密码。默认密码
只适用于受信任的局域网首次安装，不要把管理端口直接暴露到公网。

升级已有 `/data` 时，镜像默认的 `admin` 不会覆盖已经保存的密码；只有用户显式
填写其他 `ADMIN_PASSWORD` 才会重置密码。

## 8. 健康状态

镜像健康检查同时验证：

- Launcher；
- Nginx；
- API；
- Scheduler；
- Worker。

容器长时间显示“不健康”时，先查看容器日志。迁移或对账失败时 Worker 不会
启动；任一常驻进程崩溃时，整个容器会退出并由自动重启策略恢复。

如果飞牛界面提供“停止超时”或“优雅停止时间”，建议设为 `120` 秒，为 Worker
保留安全退出时间。

## 9. 备份

备份前先停止 MediaSync 容器，然后在文件管理器中完整复制：

```text
/vol1/1000/docker/mediasync
```

不要只复制 `mediasync.db`。以下内容必须一起保存：

```text
mediasync.db
mediasync.db-wal
mediasync.db-shm
config/runtime-secrets.json
```

容器停止后 `-wal` 或 `-shm` 可能不存在，这是正常现象。

## 10. 升级

按第 5 节配置 Docker Socket 后，可以在 MediaSync“系统设置”中使用实验性一键
更新。页面会等待任务结束、校验精确镜像并在候选失败时自动回滚。

也可以继续使用飞牛 Docker 界面手动升级。不需要一键更新时删除：

| 飞牛本地路径 | 容器路径 | 权限 |
|---|---|---|
| `/var/run/docker.sock` | `/var/run/docker.sock` | 读写 |

删除 Socket 后，在 MediaSync“系统设置”中会显示手动升级指引。无论使用哪种
方式，更新前都必须备份完整 `/data`。

手动升级步骤：

1. 停止当前容器；
2. 备份完整数据目录；
3. 下载新版本的精确镜像标签；
4. 删除旧容器，但不要删除宿主机数据目录；
5. 用相同端口、环境变量和 `/data` 映射创建新容器；
6. 等待健康；
7. 登录并校验云盘账号与订阅。

不要让新旧两个容器同时挂载同一个 `/data`。

## 11. 常见问题

### 页面打不开

- 确认本地端口没有冲突；
- 确认映射方向是“本地 `9090` → 容器 `9090`”；
- 确认容器为“运行中”且健康；
- 查看日志中是否有目录权限或迁移错误。

### 登录后又回到登录页

局域网 HTTP 必须使用：

```text
SESSION_COOKIE_SECURE=false
```

HTTPS 反向代理才使用 `true`。

### 忘记密码

在容器环境变量中添加或修改 `ADMIN_PASSWORD`，然后重建容器。只重启但平台没有
重新应用环境变量时，设置不会生效。

### 登录后修改密码

点击管理后台左下角管理员区域的锁形按钮，输入当前密码和两次新密码。修改成功后
所有已登录设备都会退出，需要使用新密码重新登录。新密码保存在 `/data` 中，
后续重启或重建容器仍然有效。

### 删除容器后数据没了

说明 `/data` 没有正确映射到宿主机目录，或者删除时同时删除了数据目录。恢复
备份后重新映射；没有备份时无法恢复云盘凭证密钥。
